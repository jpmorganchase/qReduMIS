# This folder contains all the problem instances used for the extensive benchmark in the paper.

In order to perform numerical simulations with TN simulator in parallel, we
divided into buckets. Then, out of all of these instances, only a few required
to call the quantum backend. These are the ones in the folder
`testbed_instances_hardware_hard`. We also include in a separate folder the
problem instances for the table in the paper under the folder `table_instances`.
